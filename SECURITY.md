# Security policy

## Supported versions

OriginLens is pre-release software. Until a release exists, security fixes are
made on the default branch and documented in repository history.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when
available. Do not open a public issue for an unpatched vulnerability and do not
include real credentials, cookies, tokens, personal data, or browsing history in
a report.

If private reporting is temporarily unavailable, open a minimal public issue
asking maintainers to enable a private channel; omit exploit details.

## Security boundaries

OriginLens is a decision-support tool, not proof of safety. Attackers are
assumed to know its source, thresholds, rules, and bundled models. Reports that
demonstrate false negatives, false positives on legitimate sites, page-to-
extension trust-boundary failures, sensitive-value access, or unauthorized
network transmission are especially valuable.
